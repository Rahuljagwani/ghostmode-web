Approach: One pass with a hash map from value to index. For each number, check if target - n is already in the map.

Complexity: O(n) time, O(n) space, versus O(n²) for the brute-force double loop.

def two_sum(nums, target):
    seen = {}  # value -> index
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i
