Собеседование Python junior редко бывает неожиданным: из компании в компанию повторяются одни и те же темы. Ниже 20 вопросов, которые задают чаще всего, с короткими ответами. Расскажите их своими словами и добавьте пример из своего опыта или пет-проекта.

## Типы данных

### 1. Какие типы данных изменяемые, а какие нет?

Изменяемые: `list`, `dict`, `set`. Неизменяемые: `int`, `float`, `str`, `tuple`, `frozenset`, `bool`.

### 2. Чем отличаются list и tuple?

`list` изменяемый, `tuple` нет. Кортеж можно использовать как ключ словаря (если все его элементы неизменяемые), и он занимает чуть меньше памяти.

### 3. Чем отличаются `is` и `==`?

`==` сравнивает значения, `is` проверяет, что это один и тот же объект в памяти. `is` используют для сравнения с `None`: `if x is None`.

### 4. Что может быть ключом словаря?

Любой хешируемый объект: строки, числа, кортежи из неизменяемых элементов. Список ключом быть не может.

### 5. Как скопировать список и в чём ловушка?

`b = a` не копирует, а создаёт вторую ссылку на тот же список. `a.copy()` или `a[:]` делают поверхностную копию. Для вложенных списков нужен `copy.deepcopy(a)`.

## Функции

### 6. Что не так с этим кодом?

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

Список по умолчанию создаётся один раз при определении функции, поэтому он общий для всех вызовов. Правильно:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

### 7. Что такое `*args` и `**kwargs`?

`*args` собирает лишние позиционные аргументы в кортеж, `**kwargs` собирает именованные аргументы в словарь.

### 8. Что такое lambda?

Короткая анонимная функция из одного выражения: `sorted(users, key=lambda u: u["age"])`.

### 9. Что такое декоратор?

Функция, которая принимает функцию и возвращает новую, добавляя поведение без изменения исходного кода.

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__}: {time.time() - start:.2f} s")
        return result
    return wrapper
```

## Итерации

### 10. Что такое list comprehension?

Короткий способ создать список: `squares = [x * x for x in range(10) if x % 2 == 0]`.

### 11. Чем генератор отличается от списка?

Генератор выдаёт значения по одному и не хранит их все в памяти. Создаётся через `yield` или выражение в круглых скобках: `(x * x for x in range(10**6))`. По нему можно пройти только один раз.

### 12. Что делает `yield`?

Возвращает значение и приостанавливает функцию. При следующем запросе функция продолжает работу с того же места.

## ООП

### 13. Что такое `self`?

Ссылка на текущий экземпляр класса. Через неё методы получают доступ к атрибутам объекта.

### 14. Чем отличаются `@staticmethod` и `@classmethod`?

`@classmethod` получает класс (`cls`) первым аргументом и часто используется как альтернативный конструктор. `@staticmethod` не получает ни класс, ни экземпляр: это обычная функция внутри класса.

### 15. Что такое наследование и `super()`?

Класс-наследник получает атрибуты и методы родителя. `super()` вызывает метод родительского класса, например `super().__init__(name)`.

## Исключения и прочее

### 16. Как обрабатывать исключения?

```python
try:
    value = int(text)
except ValueError:
    value = 0
finally:
    print("done")
```

Ловите конкретные исключения, а не все подряд через голый `except:`.

### 17. Что такое контекстный менеджер?

Объект для `with`, который гарантирует освобождение ресурса: `with open("data.txt") as f:` закроет файл, даже если внутри возникнет ошибка.

### 18. Что такое GIL?

Global Interpreter Lock в CPython: в каждый момент только один поток выполняет байт-код Python. Поэтому потоки помогают в задачах с вводом-выводом (сеть, файлы), а для вычислений используют процессы (`multiprocessing`).

## Задачи на код

### 19. Посчитайте, сколько раз встречается каждое слово в строке.

```python
from collections import Counter

def word_count(text):
    return Counter(text.lower().split())
```

Без `Counter` можно через словарь и `dict.get(word, 0) + 1`.

### 20. Проверьте, является ли строка палиндромом.

```python
def is_palindrome(s):
    cleaned = "".join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]
```

Сложность O(n) по времени и памяти.
